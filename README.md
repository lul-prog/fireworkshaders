# Firework Shaders — Forge 1.20.1

A Forge 47.2.0 / Java 17 foundation for shader-rendered fireworks and modular rocket authoring.

## Build

```sh
./gradlew build
```

Only Forge is a runtime dependency. This foundation intentionally avoids adding Lodestone or GeckoLib: its projectile/burst renderer uses the existing custom GLSL pipeline, and keeping the client dependency-free reduces loader conflicts with Oculus/Rubidium. Additional particle/render libraries can be evaluated when the larger particle suite is added.

## Pyrotechnic workstation

Craft/place the **Pyrotechnic Workstation**, then add:

1. A color chemistry powder (required).
2. A burst-shape module (required: sphere, ring, or cascade).
3. Any combination of the optional trail, crackle, and smoke modifiers (each has its own slot).

Type a name into the workstation field. The output preview is generated by the server, carries a validated `RocketDesign` payload on its item NBT, and consumes the inputs when taken. The rocket is fired with right-click.

The component items have basic survival recipes under `data/fireworkshaders/recipes/`; they are also in the Tools & Utilities creative tab.

## Implementation map

- `FireworkShaders`, `ModBlocks`, `ModBlockEntities`, `ModItems`, `ModEntities`, `ModMenus`: Forge registries and mod bootstrap.
- `block/PyrotechnicWorkstationBlock{,Entity}`: block interaction, persisted five-slot ingredient inventory, and menu provider.
- `menu/PyrotechnicWorkstationMenu`: server-authoritative ingredient validation, output preview, crafting/shift-click behavior, and input consumption.
- `client/screen/PyrotechnicWorkstationScreen`: texture-free UI and bounded custom-name field.
- `network/SetRocketNamePacket`: small C2S packet validated against the active menu id.
- `rocket/RocketDesign`: canonical color/shape/modifier model and NBT serialization.
- `entity/CustomRocketEntity`: synced design data, eased lift, drag, deterministic low-amplitude wind drift, fuse/collision detonation.
- `client/FireworkMeshes` + `ShaderBurstRenderer`: shader-lit sphere, toroidal ring, and downward cascade silhouettes.

This is the requested first slice: the workstation, design transport, named custom-rocket item, and generic custom projectile are in place. Modifier selections are serialized and synchronized, but their dedicated trail/crackle/smoke emitters are still follow-up work. The five premium preset flight patterns, remote igniter/launch-pad show director, spatial echo audio, and camera shake also need their dedicated implementation. The current burst retains the existing screen-flash post effect.
